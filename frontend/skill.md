Your task is to REVAMP the existing frontend UI into a premium, production-grade, visually unforgettable interface while keeping ALL business logic, API calls, state management, and backend integrations completely unchanged.

############################
CORE OBJECTIVE
############################

• Transform the UI into a distinctive, high-end product experience
• Remove generic AI aesthetics and template-like layouts
• Improve visual hierarchy, typography, spacing, motion, and depth
• Maintain responsiveness across mobile, tablet, and desktop
• Preserve performance and accessibility

############################
MANDATORY CONSTRAINTS
############################

• DO NOT modify any API logic, backend calls, authentication, or data flow
• DO NOT break routing, state, or business logic
• Only improve UI, layout, styling, animation, and visual composition
• Keep the code production-ready and clean

############################
DESIGN THINKING PROCESS
############################

Before writing code:

1. Understand the purpose of the page/component
2. Choose ONE bold aesthetic direction (luxury editorial, brutalist tech, retro-futuristic, industrial minimal, etc.)
3. Define:
   - typography system
   - color system using CSS variables
   - motion philosophy
   - layout composition style
4. Ensure the design feels intentional and memorable

############################
VISUAL QUALITY REQUIREMENTS
############################

• Use distinctive typography (avoid Inter/Roboto/system defaults)
• Create depth using layered backgrounds, gradients, grain, shadows, or texture
• Use asymmetric layout or unexpected composition when appropriate
• Add meaningful motion (page reveal, hover choreography, micro-interactions)
• Improve whitespace and readability
• Create strong hero or focal visual moments

############################
IMAGE GENERATION (nano-banana-pro)
############################

If hero visuals, illustrations, textures, or backgrounds would enhance the UI:

1. Generate images FIRST using nano-banana-pro
2. Write detailed prompts matching the chosen aesthetic
3. Save images inside /public or /src/assets
